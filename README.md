# AI UX Design Assistant

A chat assistant that turns an app idea written in plain English into
requirements, pages and features, UX advice with sources, wireframes,
a clickable prototype and development prompts.

## Built with
Python, spaCy, Sentence-Transformers, scikit-learn, Gradio

## How to run
1. Open the notebook in Google Colab (upload it at colab.research.google.com).
2. Run the cells from top to bottom.
